Part A — Foundations

Brand Positioning & Design Intent

IOCE integrates internationally accredited Clinical Hypnotherapy with Authentic Usui Reiki to consciously re-engineer the thoughts within the subconscious, creating meaningful and lasting transformations. The website is a premium executive transformation brand — not a wellness site, not a Reiki site, not a meditation site, not a therapy clinic. Every design decision is judged against one goal: generate qualified, trust-driven consultation bookings.

Brand personality

EmbraceAvoid
Premium, Elegant, Scientific, Professional, Human, Emotionally reassuring, Executive, Trustworthy Mystical language, Spiritual clichés, Medical/clinical appearance, Alternative-healing appearance, Loud marketing, discount banners, urgency tactics

Design inspiration references

Apple · Notion · McKinsey · Tesla · Stripe · Linear · minimal luxury consulting firms — large whitespace, clean typography, elegant motion, restrained micro-interactions.

The single feeling every screen must produce

"IOCE is a premium, trustworthy and transformational experience." Every CTA invites — it never pushes.

Rule of thumb: gold never exceeds ~5% of any given viewport. It marks the single most important action or credential in view — if everything is gold, nothing is.

Surface & elevation

Subtle shadows only (soft, low-opacity, wide blur — no hard drop shadows). Rounded corners throughout (8–24px depending on component scale). Minimal glassmorphism reserved for the video-modal panel and sticky header only — not applied broadly.

Part D — Booking Flow Deep-Dive

12 · Book Your Consultation — 3-Step Flow

This is the conversion moment. It must never feel like "checkout" — it should feel like the beginning of the client's transformation journey. One embedded card, three internal steps, no page reloads.

  1. Step 1 — Consultation Request Form: Full Name, Mobile, Email, City, Country (optional), Preferred Mode (Online / Exclusive In-Person), "What would you like help with" (free text + example topic chips)
  2. Step 2 — Consultation Summary: Read-only recap (Consultation Type, Fee, Duration, Mode, Preferred Time) + a reassurance box naming the practitioner and confirming confidentiality
  3. Step 3 — Secure Payment: Single "Proceed to Secure Payment" button (not a payment form shown upfront) → Razorpay secure checkout overlay → trust badges (Secure Payment / SSL Protected / Razorpay Verified)
  4. Confirmation: Redirect to Thank-You page — checklist of Payment, Reservation, Email, WhatsApp, Scheduling-link status

Part E — Cross-Cutting Principles

Responsive Behaviour & Accessibility

Responsive collapse rules

LayoutDesktop (>1024px)Tablet (640–1024px)Mobile (<640px)
Card grids (Who Can Benefit, Ecosystem)4–6 columns2–3 columns1 column
Roadmap milestones4-column row with connector lines2×2 gridSingle vertical column
Credentials / Session-quality cards2 columns side by side2 columnsStacked
HeaderLogo + tagline + CTA inlineSame, tagline may hideLogo mark + CTA only
Video modal16:9 landscape frame16:99:16 portrait frame

Accessibility commitments (WCAG)

  1. Skip-to-content link for keyboard users
  2. Visible focus outline on every interactive element (gold, 2px, offset)
  3. Background/looping videos never autoplay for visitors with reduced-motion enabled — they see a calm static frame instead
  4. All decorative video marked hidden from assistive tech; testimonial videos remain fully accessible with native controls
  5. Form fields carry visible labels and inline, announced error text — never colour-only error states
  6. FAQ accordion is a native, fully keyboard-operable disclosure pattern
  7. Colour pairings verified for AA contrast (white/soft-white text on navy; gold reserved for large text and interactive elements)
